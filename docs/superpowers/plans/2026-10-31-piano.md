# Piano Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Publish the approved offline iPad piano on GitHub Pages.
**Architecture:** Static ES modules, direct sample playback, versioned service worker. UI and musical math are separate.
**Tech Stack:** HTML, CSS, JavaScript, Web Audio, Node tests, Playwright browser checks.
**Spec:** docs/superpowers/specs/2026-10-31-piano-design.md

## Global Constraints
- Default F2–F5 inclusive; C/B-flat = 0/-2 semitones.
- One voice and one pointer, slide default off; all preferences saved.
- No production dependencies or runtime third-party URLs.
- Public GitHub Pages, iPad Safari installation and offline use.

## Review Focus
- Corrupt saved preferences must recover to defaults.
- Pointer cancel, app backgrounding and opening settings must silence audio.
- Resize and changing scale must stay within the 88-key register.
- Offline reload must support all instruments.
- Drag threshold must distinguish playing from moving, and ignore extra pointers.
