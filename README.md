# Piano PWA

Лёгкое офлайн-пианино для iPad: https://cnstntn-kndrtv.github.io/piano-pwa/

- Пианино, маримба, труба; одна нота одновременно.
- Начальный диапазон **Фа большой — Фа второй октавы (F2–F5)**.
- Весь инструмент A0–C8. В ⚙️ меняются масштаб (7–52 белые клавиши), положение, инструмент, тема и строй C / B♭. B♭ понижает звук на два полутона: нажатая До звучит как Си♭.
- Темы: **Классика**, **Сепия**, **Неон**.
- Сдвиг жестом по умолчанию выключен: можно вести пальцем по клавишам и играть. Включите его в настройках для перемещения клавиатуры одним пальцем.
- Масштаб и настройки сохраняются на этом устройстве.

## Установка на iPad

Откройте ссылку в Safari. В настройках приложения дождитесь «Готово к работе без интернета · все инструменты», затем Safari → «Поделиться» → «На экран Домой». Первый запуск требует интернета; далее все инструменты доступны офлайн. Если Safari очистит данные сайта, откройте его снова с интернетом. Для звука увеличьте громкость и при необходимости выключите беззвучный режим.

Приложение использует прямое воспроизведение Web Audio с `latencyHint: interactive`, без фреймворков, аудиобиблиотек и внешних запросов во время игры. Все MP3 вместе занимают около 1 МБ. Сэмплы декодируются при выборе инструмента; повторный выбор использует память. Конкретная задержка зависит от iPad и аудиовыхода: Bluetooth может заметно её увеличить. Браузерные проверки не заменяют измерения на настоящем iPad.

## Разработка и проверки

```sh
npm ci
npm test
npx playwright install --with-deps chromium webkit
OFFLINE_TEST=1 npm run test:browser
npm run serve
```

Production dependencies: **0**. Node нужен только для тестов; приложение — статические файлы. Проверки обслуживают приложение под `/piano-pwa/`, проверяя пути GitHub Pages. Изменяя приложение или звуки, увеличивайте версию кэша в `sw.js`. Обновление вступит в силу после закрытия старых вкладок приложения и повторного открытия.

GitHub Actions проверяет приложение в Chromium и WebKit, затем публикует только нужные статические файлы в GitHub Pages.

## Звуки и лицензия

Локальные MP3 — выборка FluidR3_GM из [MIDI.js Soundfonts](https://github.com/gleitz/midi-js-soundfonts), Frank Wen и участники FluidR3; преобразование Benjamin Gleitz. Согласно upstream README, Fluid Soundfont распространяется по [Creative Commons Attribution 3.0](https://creativecommons.org/licenses/by/3.0/us/). Выбраны 16 исходных записей на инструмент без изменения файлов; высота меняется при воспроизведении. Атрибуция также доступна офлайн в настройках.

Воспроизведение набора: `python3 scripts/fetch-samples.py`. Для повторной загрузки нужен интернет; для использования приложения он не нужен после первого кэширования.
